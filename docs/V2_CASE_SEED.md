> 统一字段骨架（案例落地时采用）：
> 背景 / 任务 / 需核对文件 / 判断路径 / 升级触发点 / 参考答案 / 风险提示

## Case 001 · 认购文件已签署但 AML 未完成
- 背景：投资者已签署认购文件并提交部分 KYC，AML/CDD 尚未完成。
- 任务：判断能否进入接纳流程；明确缺什么、谁有权决定。
- 需核对文件：认购文件、AML 政策、基金文件接纳条款、服务协议。
- 判断路径：认购 ≠ 接纳；AML/CDD 未闭环前不推进接纳；确认接纳权主体。
- 升级触发点：治理方要求在 AML 完成前接纳；材料矛盾无法澄清。
- 参考答案（要点）：应完成 CDD 与留痕后再由治理方接纳；Admin 不自行决定。
- 风险提示：过早接纳 → 名册与 AML 记录不一致；监管与审计质询。

## Case 002 · BVI Discretionary Trust 投资 Cayman 基金
- 背景：BVI 全权信托（Discretionary Trust）拟认购 Cayman 基金。
- 任务：完成 Trust 投资者 CDD 角色判断与文件收集；识别最终有效控制人。
- 需核对文件：信托契据、受托人决议、PTC 文件（若有）、基金 AML 政策。
- 判断路径：识别 Settlor/Trustee/Protector/受益人类别 → 判断有效控制 → 定制化收集验证。
- 升级触发点：受益人/保护人信息不透明；受托人为 PTC 需进一步穿透。
- 参考答案（要点）：按角色与控制关系定制 CDD，避免一刀切。
- 风险提示：控制关系判断错误 → 尽调不足；跨法域（BVI-Cayman）监管口径差异。

## Case 003 · Cayman ELP 单一资产基金注册判断
- 背景：Cayman ELP 仅投资单一项目，判断是否落入基金监管框架。
- 任务：按判断链评估是否构成集合投资安排、是否属于 Private Fund。
- 需核对文件：LPA、PPM、投资标的与安排描述、现行开曼基金法规与豁免条件。
- 判断路径：集合投资安排 → 排除情形 → 赎回性 → Private/Mutual 框架 → 注册判断。
- 升级触发点：边界情形需法律意见；投资者人数/结构靠近门槛。
- 参考答案（要点）：单一资产不当然排除；以事实与现行法律为准，勿仅凭名称。
- 风险提示：误判豁免 → 未注册运营处罚；跨时点规则变化。

## Case 004 · BVI Private Fund 与 Private Investment Fund 分类
- 背景：客户文件称“BVI private fund”，需确定监管分类。
- 任务：区分名称与实际制度归属，给出分析路径而非仅凭名称结论。
- 需核对文件：组织文件、募集文件、投资者属性、运作方式、FSC 现行指引。
- 判断路径：开放式 → Mutual Fund 体系；封闭式 → PIF 制度；结合投资者限制。
- 升级触发点：名称与制度归属歧义；客户坚持某分类而无依据。
- 参考答案（要点）：名称≠分类；按运作方式、投资者与现行法律判断。
- 风险提示：分类错误 → 注册/申报错漏。

## Case 005 · CRS Self-Certification 与 KYC 信息冲突
- 背景：投资者自我证明为非美税务居民，KYC 显示美国地址/电话。
- 任务：处理矛盾，不直接接受自我证明。
- 需核对文件：Self-Certification、KYC 档案、CRS 指引、账户信息。
- 判断路径：合理性检查 → 澄清取证 → 更新或重定性 → 留痕。
- 升级触发点：投资者不配合澄清；矛盾涉及重大金额或身份重判。
- 参考答案（要点）：不得直接接受；取得解释与支持文件后按流程处理。
- 风险提示：放任矛盾 → 申报错误与罚款；影响账户合规状态。

## Case 006 · Manager 要求 Admin 未经依据直接确认估值
- 背景：Manager 要求 Fund Admin 在缺乏依据时直接确认某 NAV/估值结果。
- 任务：界定 Admin 责任边界并给出处理建议。
- 需核对文件：服务协议、估值政策、投资估值资料、基金文件。
- 判断路径：谁有权批准估值 → Admin 是否具备依据 → 拒绝/升级路径。
- 升级触发点：估值无支持依据；被要求承接协议外责任；持续施压。
- 参考答案（要点）：Admin 依协议与政策履职；最终估值责任归治理方/估值主体；无依据不确认。
- 风险提示：越权确认 → 责任与声誉风险；违反估值治理预期。

## Case 007 · 关联方受让现有 LP 的全部基金权益
- 背景：现 LP 拟将全部权益转让给其关联方。
- 任务：判断转让流程、文件与新投资者的 CDD 要求。
- 需核对文件：LPA 转让条款、同意权条款、认购/转让文件、AML 政策。
- 判断路径：转让是否需治理方同意 → 受让方是否需完整 CDD → 名册更新。
- 升级触发点：关联关系无法证明；受让方为新结构需重新尽调。
- 参考答案（要点）：按基金文件判断转让同意；受让方按新投资者标准执行 CDD。
- 风险提示：跳过受让方尽调 → AML 缺口；未经同意转让的效力争议。

## Case 008 · BVI Approved Manager 接近或超过业务限制
- 背景：Approved Manager 管理规模/范围接近获批限制。
- 任务：识别临界信号并决定是否升级/补充安排。
- 需核对文件：FSC 现行指引、获批文件、基金规模清单、年度申报。
- 判断路径：监测适用基金范围与规模限制 → 评估是否需调整/升级安排。
- 升级触发点：接近上限、新基金超出范围、规则更新。
- 参考答案（要点）：持续监测；临近限制时规划补充牌照/注册或调整安排，勿静默超限。
- 风险提示：超限经营 → FSC 质询与合规处罚。
